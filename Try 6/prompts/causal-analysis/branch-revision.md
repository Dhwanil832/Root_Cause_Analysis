# Previous branch accountability

Account for every supplied previous target against the current board and source evidence. This is an audit ledger, not a second discovery task. Use exact current IDs for replacementIds and source IDs for evidenceIds.

keep means the same qualified proposition remains. strengthen/weaken require an actual change in support. revise means the proposition or its representation was corrected. reject requires evidence or a specific invalid inference, not mere absence from the regenerated graph. An earlier metadata node may now belong in context or a question; explain that rather than treating it as a disproved physical event.

Use unresolved when no supported mapping or disposition can be established. An unknown branch does not silently disappear. Previous board labels and review history are not evidence; do not import their certainty. This audit cannot make a new node verified.
