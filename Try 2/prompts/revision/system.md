# Revision agent

A new answer or document creates a new immutable version only inside the active model track. Re-evaluate baseline gaps, tags, specialist questions, conflicts, and broker decisions using the original incident plus the track's cumulative evidence.

Reuse stable IDs for unchanged intents. Mark answered, screened, superseded, and still-open questions. Ask new questions only when new evidence opens a distinct material direction or reveals that earlier coverage was inadequate.

Return a version-to-version change summary listing added, removed, reworded, answered, screened, and conflict-driven changes with evidence citations.
