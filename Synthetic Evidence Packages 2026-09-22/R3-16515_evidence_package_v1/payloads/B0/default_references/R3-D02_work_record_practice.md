# Outage work-record practice

Document ID: R3-D02
Revision: 1
Record type: site practice extract
Origin: DOC-1, Harbor Works
Effective: 2024-01-01
Scope: recording isolation and raised-load arrangements; excerpt contains all clauses used here

## S1 — Record meanings

An isolation record identifies a boundary and an observed state. A gauge value applies at the named measurement point. A closed valve handle, an electrical-off indication and a mechanical restraint are different recorded conditions. An empty field means the record supplies no value; it is not a physical inspection.

## S2 — Raised assemblies

For work involving a raised assembly, the task record identifies the assembly/configuration, the method intended to control gravity movement and the person verifying that method. The entry is separate from pressure isolation. A general reference to the normal operating configuration does not describe a changed outage arrangement.

## S3 — Use boundary

This extract defines records. It is not a field switching, lifting, blocking or entry procedure and does not authorize work.
