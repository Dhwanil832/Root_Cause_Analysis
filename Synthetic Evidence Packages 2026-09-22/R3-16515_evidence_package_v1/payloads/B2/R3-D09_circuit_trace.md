# R3 balance circuit trace

Document ID: R3-D09
Revision: 1
Record type: functional circuit trace extract
Origin: HYD-1
Observed and created: 2024-10-16
Scope: load-side volume, IV-R3 and header G-H; not a complete plant hydraulic schematic

## S1 — Connections and sensing

The loaded cylinder volume communicates with the header through IV-R3 in the traced branch. G-H is on the header side of IV-R3, not on the isolated cylinder side. With the header depressurized, fluid can leave the loaded volume by this branch if IV-R3 passes fluid despite its closed-handle position. The trace identifies no separate load-holding valve within this branch; other cylinder leakage routes were not evaluated.

The header gauge can read zero without measuring the pressure retained in the load-side volume. This trace does not turn a handle position into a leakage measurement.

## S2 — Identification limit

The shift extract calls the worked system B hydraulics. Another older summary uses A. This record uses functional identifiers IV-R3 and G-H; it does not resolve the historical A/B naming discrepancy. No operational valve sequence or load rating is provided.
