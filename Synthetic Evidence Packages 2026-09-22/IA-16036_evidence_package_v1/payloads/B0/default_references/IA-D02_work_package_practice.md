# Utilities work-package record practice

Document ID: IA-D02
Revision: 1
Record type: document-control practice extract
Origin: DOC-1, Harbor Works
Effective: 2024-01-01
Scope: change routing and work-packet issue records; not a field isolation procedure

## S1 — Issue status

The packet issue register records the instruction revision supplied with a work order. A draft revision has no operating effective date until approved and issued. Availability in an engineering draft folder is not distribution to a work crew.

## S2 — Routing rule

In the change register, work-package impact = Yes creates an ECP review/distribution task. Work-package impact = No does not create that task. Field-installation completion and instruction approval are separate statuses. The issue register, not the existence of a draft, records what entered the issued packet.

## S3 — Interpretation boundary

These rules define records and routing. They do not establish that a particular change was correctly classified, that a crew read an instruction, or that a physical isolation was safe. No work sequence is authorized by this extract.
