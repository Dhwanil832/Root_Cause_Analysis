# Other / Novel Condition

## Purpose

Capture a material investigation direction that cannot reasonably fit any defined tag without creating a permanent tag from a one-off description.

## Activate this tag only when

- Every defined tag has been considered.
- The condition could materially affect the causal analysis.
- Assigning it to an existing tag would hide or distort the investigation direction.

Do not use this tag as a shortcut for uncertainty, incomplete reading, missing information, or an unusual object that still belongs to Equipment or tool involvement.

## First-pass branching questions

1. What condition or subject is not represented by the existing tags?
2. What facts show that it is materially connected to the event?
3. Which existing tag is closest, and why is it insufficient?
4. What distinct investigation questions does this condition require?
5. Is it genuinely novel, or is only the wording or specific object unusual?
6. Has the same theme appeared in other incidents under different language?
7. What evidence could confirm or screen out this direction quickly?
8. Should the condition remain a case-specific note or be proposed for taxonomy review?

## If this tag was processed before

Reuse the definition, supporting facts, nearest existing tag, and prior screening. Ask only what is needed to determine materiality, recurrence, or correct reassignment.

## Taxonomy-review rule

Do not create a new permanent tag from one case. Propose a new tag only when the theme:

- recurs across incidents;
- activates a meaningfully different line of questioning;
- cannot be handled clearly by an existing guide; and
- improves investigation routing enough to justify added complexity.

## Expected result

Record the novel condition, material connection, closest existing tag, minimum investigative path, recurrence evidence, and recommendation to retain, reassign, or propose taxonomy review.
