# Fixed-meaning v4 acceptance — frozen before live calls

This is a narrow claim-review evaluation, not an RCA success score. Same saved Qwen digest, temperature, context and evidence. No model mixture, storyteller, new investigation or edited verdicts. The preserved application run must remain paused and hash-identical while testing.

Each case has two distinct calls: evidence-blind meaning, then evidence comparison against the saved meaning. Review must preserve the meaning, cite original lines for definitive relations, retain both sides of actual source conflicts, and explicitly fail incomplete reviews. A syntactically valid answer is insufficient. Inspect interpretation AND citations, not just the final status.

## Resume gate

All 18 cases must complete the two stages without scope-changing interpretation, unsupported approval, missed required conflict, invented conflict, missing definitive citations, or state mutation. Statuses alone do not pass a case. Any critical failure keeps the preserved investigation paused. Record failures, not another prompt rewrite plus a hidden rerun. Passing would authorize only the next bounded inspection step, not a claim of generalized robustness.
