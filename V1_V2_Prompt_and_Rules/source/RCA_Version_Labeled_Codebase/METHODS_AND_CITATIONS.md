# Research inspirations and implementation boundaries

This document links actual V2 methods to **specific prior research**. These are inspirations, **not reproduced algorithms**. No novelty or performance comparison against the original paper is implied by adopting a related design principle.

| Reference | Actual published mechanism (summarized) | This implementation borrows | Explicit gap |
|---|---|---|---|
| Feng et al., **IRIS** (ACL 2025): https://aclanthology.org/2025.acl-long.463/ | Iterative retrieval, hybrid statistical+LLM causal graph discovery, including proposals for missing causal variables. | Specialist stores conditional missing premises and links hypotheses to unanswered scoped questions; avoids treating missing variables as facts. | No statistical causal discovery, novel relation learner, retrieved-corpus graph estimator or IRIS benchmark replication. |
| Fang et al., **MINT** (ICML 2026): https://proceedings.mlr.press/v306/fang26i.html | Neuro-symbolic interaction tree and self-play for deciding consequential elicitation of missing information in object-driven planning. | Lead ranks current gaps by relevance and affordable access to evidence within a bounded single-step policy. | No symbolic scenario tree, optimized elicitation policy, calibrated value-of-information probabilities or self-play training. |
| Hu et al., **HARIS** (ACL 2026): https://aclanthology.org/2026.acl-long.119/ | RL-trained coordination between reasoning-guided search and search-informed verification. | Specialist/Lead generate evidence questions; Evidence Worker narrows public sources and returns new observations for reassessment. | No trained hierarchical two-agent policy, iterative search optimization or HARIS outcome-based reward learning. |
| Gao et al., **ALCE** (EMNLP 2023): https://aclanthology.org/2023.emnlp-main.398/ | Evaluates correctness, citation quality and retrieval-grounded outputs. | Exact source spans, provenance and human-review sheet distinguish cited claims from causal validation. | Exact quote matching is weaker than textual entailment; no ALCE automatic metrics or independently scored citations. |
| OpenAI **Structured Outputs**: https://developers.openai.com/api/docs/guides/structured-outputs | JSON Schema-constrained outputs where supported. | Each role has a strict task-specific local output/quote contract, bounded rejection and repair; prompt shows explicit JSON shape. | Actual provider constrained decoding is optional/availability-dependent; a JSON object may still be semantically wrong. |
| OpenAI **Prompt Engineering**: https://developers.openai.com/api/docs/guides/prompt-engineering | Clear role instructions, examples, model-specific techniques and evaluation after changes. | Independent Markdown prompts, generic contrastive examples, evidence trust boundaries, SHA hashes and prompt-only ablations. | Prompt performance not measured on an independent LLM in this build. |

**Our present V2**: bounded, paper-inspired, executable methods with clearly reported limitations. **Proposed V3**: separate research problem of coupling changing causal-frontier uncertainty with *multi-step counterfactual evidence-access decisions*. Do not claim V2 already solves that V3 problem.
