# Carrier assembly functional description

**SYNTHETIC RESEARCH FIXTURE. Not an authentic company record.**

Record: E02 | Case: FCB-01 | Asset: RB-3
Record owner: Engineering records
Coverage: Baseline arrangement before Day 0

## Assembly
The carrier is connected through link arms to hydraulic lifting yokes. The yokes raise and lower the carrier. The baseline arrangement has one keeper plate on each link arm. A keeper is intended to retain engagement within its specified operating geometry.

## Operating envelope
The normal operating arrangement includes the backup rolls. Outage arrangements may remove components that delimit the normal travel envelope. This description is not an as-found survey of the Day 0 equipment.

## Information ownership
Engineering records maintains geometry and configuration material. Maintenance records holds work instructions and completed job packs. Shift operations retains handover records. Controls retains available operating logs. Temporary-work and isolation records are held by the outage coordinator.
