# Utilities area and service directory

Record ID: IA-D01 | Revision: 2 | Effective: 2024-04-01

Synthetic evaluation record. All equipment identifiers and layout details are fictional and are not operating instructions.

## Service areas

The Utilities air gallery serves the 1SC dryer group and distributes instrument air to the RHOB process area. RHOB is the local area name used in these records; it is not an individual compressor identifier. The 1SC gallery and RHOB instrument-air station are separate operating locations.

| Location | Equipment/service | Normal record custodian |
| --- | --- | --- |
| North gallery | Site air-header connection, local indication P-U | Utilities operations |
| Dryer aisle | Dryer group D-101 and main-route valves M-101/M-102 | Utilities maintenance |
| East service rack | Auxiliary line installation area | Projects and Utilities |
| RHOB service station | Receiving header H-R and indication P-R | RHOB operations |

## Roles

Utilities prepares the maintenance boundary. RHOB operations observes the receiving process. Maintenance receives the work boundary only after its release. A maintenance work order being scheduled is not a record that the boundary has been released.

This directory is a location index. It is not a current piping diagram and does not establish valve positions or the pressure available at any given time.
