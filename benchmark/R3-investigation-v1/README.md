# R3 verified package and frozen evaluation sheet

This package prepares the four-way GPT-5.5/Qwen comparison. **No new model runs have been made.** All new score cells are blank.

- **17 unchanged synthetic surrounding records**, with initial evidence separated from custodian-held evidence.
- **96 binary expected-output checks across 12 stages.** Eight final-board checks preserve continuity with the earlier evaluation.
- **17 independent clean-input packets**, each using reviewed correct predecessor state and the frozen actual role prompt.
- Three planned fresh repetitions per model/input condition. The spreadsheet contains 1,152 scoring rows, stage scores and a four-column comparison. Repetition of one developed case is not evidence of general RCA accuracy.
- Request-driven connected evidence delivery policy, source hashes, archived current prototype and reviewed causal-output defects.

Read [the verification and prototype review](REVIEW.md), then [the frozen evaluation protocol](PROTOCOL.md). Detailed criteria are in `private/evaluator/criteria.json` and `EVALUATION_SHEET.md`. The workbook is in `outputs/01a0cef3-83d5-7bc1-a0a5-45c70c3255a3/R3_Evaluation.xlsx`.

The original chart, ground truth, criteria and scores are evaluator-only. The models receive only the selected packet, effective prompt and allowed incident sources. The full custodian inventory must not enter a connected model's context just because it is in this directory.

Run `python3 verify_package.py` for offline hash/reference checks. It never calls a model. A freeze is a content snapshot, not filesystem write protection. Keep the original frozen workbook blank; write scored copies/results outside this directory and preserve model-call artifacts.

**Execution qualification remains open:** a reproduced specialist scheduling defect, supported-orphan review policy, integrated Qwen adapter and context/output-budget checks. See REVIEW.md. This package freezes expected outputs without claiming a fault-free harness. Any common runtime repair must be versioned before either model is run.
