# Independent evaluation plan

Prepared by the coordinating agent before Qwen's initial version is complete. This file stays outside the app's evidence inputs.

## Experiment being tested

Can a persistent, separate story agent operate the existing Try 4 app, answer actual model questions from a fixed R3 incident world, preserve consistency across versions, and bring an investigation to a supported conclusion or a documented evidence limit?

## What to audit

- Initial inputs contain only the historical description, three starter documents, and the eight registered defaults.
- Every later release answers an actual baseline, specialist, canonical, or verification question, with sources and limitations.
- Canonical owners and shared routes survive in the saved question records; repeated questions are distinguished from new information needs.
- Hidden facts and evidence boundaries remain fixed. No raw test, measurement, video, witness, or approval is invented to satisfy a leading question.
- Every Qwen version and app checkpoint is preserved. Source delivery, retrieval, extraction, and use are assessed separately.
- Challenge evidence appears only at the declared point and retains its provenance cues.
- No human approval, synthetic causal node, alternative model, or application change is used to force completion.
- A stop is justified by the evidence record: supported investigation, unavailable evidence, repeated lack of progress, or execution failure.

## Outcome reporting

Report the actual number of model versions, answered requests, released documents, model failures, causal maturity, and any actions. Distinguish a successful simulator interaction from a successful completed RCA.

Apply the established R3 100-point rubric only after freezing the last version and release ledger. Cite concrete output and distinguish model error, app routing or contract error, simulator error, and missing source evidence. Report which critical findings were actually testable.

The earlier 68/100 benchmark supplied the complete packet at creation; this run supplies evidence progressively. Its score is context for comparison, not a controlled measurement of an improvement caused solely by the story agent.
