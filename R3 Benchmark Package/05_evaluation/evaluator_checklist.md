# Evaluator checklist

## Blindness

- [ ] No withheld RCA file was uploaded or quoted to the model
- [ ] No answer-bank file was uploaded wholesale
- [ ] The model did not receive another model's output

## Run control

- [ ] Model identity and exact version recorded
- [ ] Application version recorded
- [ ] Settings and time ceiling recorded
- [ ] Default and starter documents matched the protocol
- [ ] Every progressive evidence release was logged
- [ ] Challenge evidence timing matched comparable runs

## Output integrity

- [ ] Every committed version preserved
- [ ] Stage errors and fallback content identified
- [ ] Questions asked, merged, skipped, and answered preserved
- [ ] Claims retain sources and uncertainty
- [ ] Causal links point forward from condition or action to consequence
- [ ] Corrective actions map to verified or explicitly provisional causes

## Scoring

- [ ] Evidence availability checked before assigning zero credit
- [ ] Each rubric score cites model output
- [ ] Causal-chain recovery level assigned
- [ ] Major misses classified by failure type
- [ ] Raw score and testable score reported
