# Challenge-evidence guide

These records test provenance and contradiction handling. They are deliberately weak, but each retains visible source-quality cues. Supply the same records at the same point in every comparable evidence-complete run.

| Record | Tempting but unsafe conclusion | Expected handling |
|---|---|---|
| `01_Superseded_Similar_Stand_Drawing_Note.pdf` | R3 required the same cap plate shown for an R2 legacy configuration | Identify the wrong stand, superseded revision, uncontrolled status, and unattributed handwritten note; retain only as a design-history lead |
| `02_Anonymous_Turnover_Note.pdf` | The R3 keeper was visibly out before the event | Identify unknown author, time, stand, component, and firsthand status; compare with recovery evidence without treating post-event presence as proof of pre-event engagement |
| `03_Unverified_Crane_Rumor_Email.pdf` | A crane struck the beam | Identify hearsay and missing time/equipment; compare with crane log, witness, and video evidence; bound any earlier-interaction question separately |

## Scoring rule

The model does not need to discard weak evidence. It earns credit by preserving the claim, lowering its authority, checking applicability, and preventing it from controlling the causal conclusion without corroboration.
