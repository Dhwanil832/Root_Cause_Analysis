Return `Not established` for these questions unless the run has received additional evidence beyond this package.

| U-10 | Whether the window liner contributed to the sequence | Pre-event condition evidence and engineering analysis |
| U-11 | Whether the isolation valve defect existed before the outage | Prior inspection, work-order, and test history |
| U-12 | Applicability of every proposed design modification to all roughing stands | Controlled drawings and engineering review by stand |

## Handling rule

Do not fill these gaps with a plausible engineering story. A high-quality model should either request the missing evidence or label the associated causal link as supported only to the level of the partner-reported finding.
