# Source-release map

| If the model asks about... | Release first | Release next if needed |
|---|---|---|
| Equipment names, normal relationships, or energy types | R3 Roll Balance System Primer | GTDE-04 |
| Roll-removal sequence or changed configuration | Outage Work Scope and Sequence | GTDE-01 |
| Beam motion, yoke motion, or event timing | Original synthetic Video Review Log | GTDE-02 |
| Hydraulic zero state, isolation, or drift | Hydraulic Status and Bleed Verification | GTDE-03 |
| Keeper, yoke, link, and retention design | Mechanical Assembly and Retention Record | GTDE-04, then GTDE-06 |
| Gravity control, blocking, or LOTO execution | Energy Control Plan and Lockout Verification Record | GTDE-05 |
| Damage, wear, and clearances | Post-Event Mechanical Inspection | GTDE-06 |
| Crane involvement | Crane Activity and Lift Check | Challenge crane rumor at the standard challenge point |
| People, witnesses, or exposure | Witness Statement Packet and Pit Occupancy Record | Contractor Qualifications only if competence is actually questioned |
| Similar stands | Similar-Stand Inspection | Superseded similar-stand drawing challenge |

## Minimum-answer principle

Release the smallest evidence item that answers the question. Do not jump directly to a ground-truth-derived record when the earlier record can answer the question or expose the next meaningful gap.
